# Исправления для обновления иконок и фотографий

## Проблема
Когда в админ-панели изменяются иконки (Benefits) и фотографии категорий, они не обновляются на главной странице.

## Причины
1. **Иконки**: В админ-панели сохранялись значения из скрытых input'ов, но они не всегда содержали правильные значения иконок
2. **Фотографии категорий**: Не сохранялись в localStorage вообще (были закомментированы)
3. **Синхронизация**: Главная страница не проверяла изменения в localStorage достаточно часто

## Примененные исправления

### 1. **admin.js** (строки 606-613)
Добавлено сохранение иконок и фотографий категорий:
```javascript
benefitIcon1: document.getElementById('benefitIcon1').value || 'fa-shipping-fast',
benefitIcon2: document.getElementById('benefitIcon2').value || 'fa-fish',
benefitIcon3: document.getElementById('benefitIcon3').value || 'fa-star',
benefitIcon4: document.getElementById('benefitIcon4').value || 'fa-shield-alt',
catImage1: document.getElementById('catImage1').value,
catImage2: document.getElementById('catImage2').value,
catImage3: document.getElementById('catImage3').value,
catImage4: document.getElementById('catImage4').value,
```

### 2. **app.js** (строки 1060-1068)
Улучшена функция `loadSettings()`:
- Теперь сначала проверяет localStorage (где админ-панель сохраняет данные)
- Затем использует Supabase как резервный вариант

### 3. **app.js** (строки 1119-1136)
Исправлено обновление иконок и фотографий:
- Иконки обновляются через `innerHTML` контейнера `.benefit-icon`
- Фотографии обновляются через `style.backgroundImage`
- Добавлены логи для отладки

### 4. **app.js** (строки 1324-1348)
Улучшена периодическая проверка обновлений:
- Интервал сокращен с 2000ms до 1000ms
- Добавлена проверка изменения JSON строки настроек
- Обновление вызывается только при реальных изменениях

## Как тестировать

1. **Откройте главную страницу** (index.html) в браузере
2. **Откройте админ-панель** (admin.html) в другой вкладке
3. **Войдите** с логином: `admin`, пароль: `admin123`
4. **Перейдите** на вкладку "Налаштування"
5. **Измените иконку** для одного из Benefits (нажмите на другую иконку в сетке)
6. **Загрузьте новую фотографию** для одной из категорий
7. **Нажмите** "Зберегти налаштування"
8. **Вернитесь** на главную страницу (вкладка с index.html)
9. **Проверьте**: иконка и фотография должны обновиться в течение 1-2 секунд

## Если обновления все еще не работают

1. **Откройте DevTools** (F12)
2. **Перейдите** на вкладку Console
3. **Проверьте логи** - должны быть сообщения "Settings changed, updating..."
4. **Проверьте localStorage**: 
   ```javascript
   JSON.parse(localStorage.getItem('storeSettings'))
   ```
5. **Очистите кэш браузера** (Ctrl+Shift+Delete) и перезагрузите страницу
