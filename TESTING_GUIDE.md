# Руководство по тестированию обновления иконок и фотографий

## Быстрый старт

### Шаг 1: Откройте две вкладки браузера
- **Вкладка 1**: `index.html` (главная страница магазина)
- **Вкладка 2**: `admin.html` (админ-панель)

### Шаг 2: Войдите в админ-панель
- Логин: `admin`
- Пароль: `admin123`

### Шаг 3: Перейдите в настройки
- Нажмите на "Налаштування" в левом меню

## Тестирование иконок Benefits

### Как изменить иконку:
1. В админ-панели найдите секцию "Benefits - Описи та іконки"
2. Для каждого benefit есть сетка с иконками
3. Нажмите на новую иконку (она подсветится синим)
4. Нажмите "Зберегти налаштування"

### Что должно произойти:
- На главной странице иконка должна обновиться в течение 1-2 секунд
- Если обновления нет, проверьте консоль браузера (F12 → Console)

### Логи для проверки:
```
✓ Updated benefitIcon1 to: fa-star
✓ Updated benefitIcon2 to: fa-heart
```

## Тестирование фотографий категорий

### Как изменить фотографию:
1. В админ-панели найдите секцию "Картинки категорій"
2. Нажмите "Завантажити" для нужной категории
3. Выберите новое изображение с компьютера
4. Нажмите "Зберегти налаштування"

### Что должно произойти:
- На главной странице фотография категории должна обновиться в течение 1-2 секунд
- Если обновления нет, проверьте консоль браузера

### Логи для проверки:
```
✓ Updated catImage1: data:image/jpeg;base64,...
✓ Updated catImage2: data:image/png;base64,...
```

## Отладка в консоли браузера

### Открыть консоль:
- Нажмите **F12** или **Ctrl+Shift+I**
- Перейдите на вкладку **Console**

### Проверить текущие настройки:
```javascript
JSON.parse(localStorage.getItem('storeSettings'))
```

### Проверить конкретную иконку:
```javascript
JSON.parse(localStorage.getItem('storeSettings')).benefitIcon1
```

### Проверить конкретную фотографию:
```javascript
JSON.parse(localStorage.getItem('storeSettings')).catImage1
```

### Принудительно обновить:
```javascript
loadSettings()
```

## Возможные проблемы и решения

### Проблема: Обновления не появляются
**Решение:**
1. Проверьте консоль на ошибки (F12 → Console)
2. Убедитесь, что вы нажали "Зберегти налаштування"
3. Очистите кэш браузера (Ctrl+Shift+Delete)
4. Перезагрузите обе вкладки (F5)

### Проблема: Иконка обновилась, но фотография нет
**Решение:**
1. Проверьте размер файла (максимум 5MB)
2. Убедитесь, что формат изображения поддерживается (JPG, PNG)
3. Попробуйте загрузить другое изображение

### Проблема: localStorage переполнен
**Решение:**
1. Откройте консоль (F12 → Console)
2. Выполните: `localStorage.clear()`
3. Перезагрузите страницу
4. Добавьте товары и настройки заново

## Контакты для поддержки

Если проблемы не решены:
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что используется современный браузер (Chrome, Firefox, Edge)
3. Попробуйте в приватном окне браузера
4. Проверьте, что localStorage не отключен в настройках браузера
